# Lesedi la Batho Website

## Project Overview

Lesedi la Batho is a modern community organisation website developed as a school web development project.

The website provides information about the organisation, its programmes, latest news, and contact details. It also allows visitors to submit enquiries.

The website was designed with a clean, modern and professional appearance while keeping the HTML structure simple and semantic.

---

## Features

- Modern and responsive design
- Mobile-friendly layout
- Professional navigation bar
- Hero section on the home page
- Community programme cards
- Image integration
- Hover animations and effects
- Contact information section
- Enquiry/contact form
- Responsive design for phones, tablets and computers
- Semantic HTML structure
- No `<div>` elements used
- Consistent navigation across all pages

---

## Technologies Used

### HTML5

HTML5 is used to create the structure and content of the website.

Semantic HTML elements are used instead of `<div>` elements, including:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`
- `<form>`
- `<label>`
- `<input>`
- `<textarea>`
- `<button>`

### CSS3

CSS3 is used to style and design the website.

The stylesheet includes:

- Responsive layouts
- Flexbox
- CSS Grid
- Gradients
- Shadows
- Rounded corners
- Hover effects
- Image effects
- Form styling
- Mobile breakpoints
- Transitions and animations

## Website Pages

### 1. Home
 `index.html`

The home page introduces Lesedi la Batho and provides an overview of the organisation's main activities.

It includes:

- Hero image
- Introduction
- Call-to-action button
- Food Relief
- Skills Development
- Youth Mentorship

---

### 2. About Us
`about.html`

The About Us page provides information about the organisation.

It includes:

- Who We Are
- Our Mission
- Community Support
- Skills Development
- Youth Development

---

### 3. Programs
`services.html`

The Programs page explains the main activities offered by Lesedi la Batho.

Programmes include:

- Food Relief
- Skills Development
- Youth Mentorship
- Community Development

---

### 4. News

`news.html`

The News page provides updates about the organisation and its community activities.

It includes:

- Community Support
- Growing Together
- Skills Development

---

### 5. Get Involved
 `enquiry.html`

The Get Involved page allows visitors to send an enquiry.

The form includes:

- Full Name
- Email Address
- Phone Number
- Message
- Submit button



### 6. Contact

The Contact page provides ways for visitors to contact the organisation.

It includes:

- Location
- Email address
- Phone number
- Enquiry link
